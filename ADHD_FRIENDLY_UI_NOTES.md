# ADHD-Friendly UI Notes for Orchestrator

Research themes from UX/accessibility articles and dashboard design guidance:

- Reduce cognitive load: fewer competing elements, fewer visible decisions at once.
- Clear hierarchy: make the primary next action obvious before showing supporting detail.
- Minimal distractions: avoid bright multi-color dashboards, heavy gradients, motion, and dense cards.
- Whitespace helps readability: separate sections with space, not borders everywhere.
- Consistent typography and colors: readable system fonts, strong contrast, restrained palette.
- Progressive disclosure: show summary first, details on click.
- Focus mode: let the user reduce the UI to only what needs attention.
- Larger targets: make primary actions easy to hit and avoid tiny controls.
- Calm status color usage: color should signal state, not decorate everything.

Design direction for Ronnie:

- Light/white UI.
- Polished gray depth.
- Navy blue as the main accent and action color.
- One obvious top priority.
- Board remains useful, but cards are calmer and less dense.
- Details move into side panel/modal instead of showing all at once.
- Floating mic stays visible, but not visually loud.
